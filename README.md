## 一、产品概述（Slogan & 一句话定位）

**w.x 品牌AI助手**是一款专为中文市场打造的 **GEO（生成式引擎优化）** 全流程平台，聚焦品牌在国产大模型（豆包、DeepSeek、通义千问、智谱、Kimi）AI 问答中的**被提及与被引用**。平台集成了关键词研究、AI 内容创作、质量审核、GEO 品牌诊断、站点审计、收录监测等八大核心模块，从内容生产到效果验证形成完整闭环，帮助企业和营销团队系统性提升品牌在 AI 时代的可见度与影响力。

**为什么是 GEO 而非 SEO？**
- 传统 SEO 优化的是品牌在百度、Google 搜索结果页中的蓝色链接排名；
- GEO 优化的是品牌在 AI 大模型问答中**被提及、被引用、被推荐**的概率。
- 超过 50% 的中国用户已通过 AI 问答进行购前调研，**GEO 已成为数字营销的新基建**。

## 三、8 大核心功能

### 1. 仪表盘 — 项目运营一目了然

KPI 卡片实时展示关键词总数、文章数量、E-E-A-T 质量评分；意图分布图直观呈现用户搜索意图构成；待办事项与最新动态帮助团队高效协作。

- 多项目管理与切换
- KPI 指标实时追踪
- 意图分布可视化
- 最新内容与审计报告快速预览

### 2. 一键拓词 — AI + 搜索引擎双引擎驱动

从种子关键词出发，智能拓展海量高价值关键词，支持多模型并行拓展，一次操作获取更全面的关键词矩阵。

- 多 AI 模型并行拓展（DeepSeek / Kimi / 千问 / 豆包 / 智谱）
- 搜索引擎采集（Google / 百度 / Bing）
- 实时网络搜索增强
- 搜索量、难度、意图自动分析
- 四层关键词体系（品牌层 / 行业层 / 意图层 / 长尾层）
- 导出 Markdown / CSV

### 3. AI 创作 — 基于可控模板的智能内容生成

内置 4 种风格模板与智能排版工具，支持引入资源库附件和知识库文档，产出可直接发布的 GEO 优化内容。

- 4 种风格模板（专业 / 轻松 / 技术 / 营销）
- 多 AI 平台模型自由选择
- 资源库附件与知识库文档引用
- 实时网络搜索增强内容时效性
- 智能排版（标题加粗 / 智能分段 / 标签高亮 / 自动编号）
- 富文本编辑器
- 导出 Markdown / HTML / Word

### 4. 质量审核 — 基于 Google AI Search 最佳实践的四维审核

不仅给出评分，更提供可执行的修改建议，让内容同时满足搜索引擎和 AI 大模型的双重标准。

- 四维评分（内容价值 / 技术结构 / AI 搜索适配 / 合规风险）
- 雷达图可视化
- 问题定位（P0 紧急 / P1 重要 / P2 建议）
- AI 模型适配预览
- 内容原创性分析
- Schema 结构化数据建议
- AI 创作透明度检查
- 合规检查（Google 垃圾内容政策）
- 导出 Markdown / HTML / JSON / PNG

### 5. GEO 指南针 — AI 驱动的 GEO 决策引擎

五大模块覆盖 SEO 全流程决策需求。

| 子模块      | 说明                                       |
| -------- | ---------------------------------------- |
| 关键词聚类    | 按主题自动聚类，含搜索量、难度、意图分类                   |
| 页面规划蓝图   | 从 0 到 1 规划新页面，输出结构/内容/SEO/UX/技术映射       |

| 收录监测     | 文章搜索引擎收录（Google/百度）及 AI 引用监测           |

### 6. GEO 品牌优化 — 8 阶段品牌可见度全流程

从语义理解到效果验证的 8 阶段工作流，每个阶段独立运行，也可串联形成完整工作流。

```
阶段0: 意图识别 → 阶段1: 关键词拓展 → 阶段2: 引用模拟

    ↓
阶段6: 效果验证 → 阶段7: 复盘优化
```

- 模拟 5 大国产大模型引用特征
- 6 种内容模板（产品评测 / 选购指南 / 对比分析 / 教程指南 / FAQ / 深度分析）
- 发布平台推荐与策略建议
- 效果验证记录与追踪
- 快速内容引用潜力评分
- 导出完整报告（Markdown / PDF / Word）

### 7. 资产库 — 统一管理所有产出内容

支持全文搜索、批量删除与批量导出，让数字资产不再散落各处。

- 5 大分类（关键词 / 文章 / 审核报告 / 知识库 / AIO 报告）

- 批量删除与批量导出

## 四、产品核心优势（差异化亮点）

### 优势 1：聚焦 GEO，押注 AI 搜索新基建
率先提出面向国产大模型的生成式引擎优化方法论，覆盖豆包、DeepSeek、千问、智谱、Kimi 五大平台，抢占 AI 时代品牌营销新高地。

### 优势 2：双引擎驱动，数据更全面
"AI 推理 + 真实搜索"双通路：一边是多个国产大模型并行拓展，一边是 Google / 百度 / Bing 真实搜索结果采集，二者结果自动融合去重，避免单一数据源偏差。

### 优势 3：模板化内容生产 + 智能审核闭环
从关键词 → 模板化内容生成 → 四维质量审核 → 收录与引用监测，全流程闭环。所有内容在发布前都经过 E-E-A-T 风格审核，AI 引用潜力可量化。

### 优势 4：四层关键词体系 + P0/P1/P2 优先级
品牌层 / 行业层 / 意图层 / 长尾层四层结构覆盖完整搜索意图，P0/P1/P2 优先级帮助团队聚焦高价值任务。

### 优势 5：12+ AI 模型自由选择，国产化优先
同时支持 DeepSeek、Kimi、豆包、千问、智谱等 5 大国产模型与 OpenAI、Claude 等国外模型，并提供 OpenAI 兼容 / Anthropic / 火山引擎 / MCP 等自定义协议，企业可按成本与合规需求自由组合。

### 优势 6：本地化数据，资产安全可控
所有数据存储在本地 SQLite 数据库，API Key 仅保留在用户设备上，不上传任何服务器。支持数据备份与恢复，跨设备迁移无门槛。

### 优势 7：八大模块一体，免工具拼接
覆盖关键词研究、内容生成、质量审核、站点审计、收录监测、资产管理、模型配置、效果追踪的一体化工作台，告别多工具拼凑。

## 七、常见问题 FAQ

**Q1：w.x 品牌AI助手与传统 SEO 工具有什么区别？**
传统 SEO 优化的是百度、Google 结果页中的蓝色链接排名；GEO 优化的是品牌在豆包、DeepSeek、千问等 AI 问答中的被提及与被引用。超过 50% 的中国用户已通过 AI 问答进行购前调研，w.x 同时覆盖 SEO 与 GEO 需求。

**Q2：需要配置 API Key 吗？**
需要。在「配置中心」可添加 DeepSeek、Kimi、豆包、千问、智谱等国产模型的 API Key，也支持 OpenAI、Claude 等国外模型。每个 Key 都有一键测试按钮验证可用性。

**Q3：支持哪些 AI 模型？**
12+ 国内外大模型：DeepSeek、Kimi、通义千问、豆包、智谱 GLM、OpenAI（GPT-4o）、Claude（Anthropic），以及兼容 OpenAI / Anthropic / 火山引擎 / MCP / 原生协议的自定义平台。

**Q4：GEO 品牌诊断报告包含哪些内容？**
11 个章节：品牌概况速览、AI 可见度综合评分（含雷达图）、五大平台 AI 可见度现状、官网技术 SEO 诊断（8 项）、内容结构与 AI 可引用性分析（6 维度）、E-E-A-T 信号评估、外部引用生态分析（7 大渠道）、竞品 AI 可见度对标、AI 可见度提升路线图、核心发现总结、行动优先级总表。

**Q5：支持哪些导出格式？**

| 模块       | 导出格式                         |
| -------- | ---------------------------- |
| 关键词研究    | Markdown / CSV               |
| AI 创作    | Markdown / HTML / Word       |
| 质量审核     | Markdown / HTML / JSON / PNG |
| GEO 品牌优化 | Markdown / PDF / Word        |
| GEO 指南针  | Markdown / CSV / JSON / Word |
| AIO 分析   | Markdown / HTML / CSV / PDF  |

**Q6：数据安全如何保障？**
所有数据存储在本地 SQLite 数据库，API Key 仅保存在用户设备上，不上传任何服务器。支持数据备份与恢复，可导出设置文件迁移到其他设备。
